# 與先前 Caltech 換群實驗的比較

比較對象為 9/21 stage-aligned 換群實驗、10/12 修正中心重測，以及本次平移增強後的案例分析。

## 設定與可比範圍

| 項目 | 9/21 舊實驗 | 10/12 修正重測 | 本次 |
|---|---|---|---|
| 模型 | 原模型 epoch 66 | 同一原模型 | 原模型 vs 全類別平移增強模型 epoch 84 |
| 取樣 | 漏加 annotation bbox offset 的舊位置 | 修正後輪廓點平均中心 | 同修正中心 |
| 輸入與位移 | 160-in-224；stage 0/1/2 各 8/16/32 px、四方向 | 同畫布；另掃 0/4/8/16/32 px | 案例限制 stage 0/1/2 各 8/16/32 px、四方向 |
| 類別 | 160 張 airplanes | 同 160 張 airplanes | 同飛機＋22 chandelier＋20 brain |
| 案例挑選 | 按平移後 margin 優先，每 stage 各選換群／同群三例 | 以完整配對統計為主 | 四種群／預測組合，優先高 cosine，每 model/class/stage 內 source 不重複 |

9/21 舊位置結果可保留作歷史現象描述，但不能當成正確物體中心。本次增強效果以 10/12 修正重測作直接基準。不同挑例規則也使展示圖片不能當作換群嚴重程度的抽樣比較。

核對：本次 baseline airplanes 的 1,920 筆 stage-aligned 配對，與 10/12 逐筆資料依 source/stage/shift/direction 對齊；群指派及預測完全一致，cosine 最大絕對差為 1.79e-07。

## 對比解讀

1. 舊實驗已有「局部特徵相似、群指派可能改變」及「局部不換群，分類仍會改變」現象。本次保留這兩個觀察，並以完全相同 crop 的案例明確展示；不是全新的現象。
2. 本次新增訓練對照：Stage 2 / 32 px，換群率由 10.94% 降至 6.72%，但預測改變率由 39.06% 大幅降至 0.94%。分類穩定性的改善幅度明顯大於局部群穩定性的改善幅度。
3. Stage 0 / 8 px，換群率兩模型均為 4.84%，預測改變率仍由 2.81% 降至 1.72%。因此不能把增強效果只歸因於中心 token 更少換群。
4. 舊實驗換群組的 margin 較小，支持分群邊界附近的小漂移；本次高 cosine 換群案例與這個解讀相容，但沒有分離位置編碼、attention 與 merging 的作用，不能宣稱已驗證機制。
5. 新增吊燈與腦部影像補足高準確率飛機較少的失敗案例；它們是依 validation 表現探索性挑選，沒有相同的舊類別對照，不能把它們當成舊實驗的直接重現。

每方向重用同一來源影像；以上是描述性比例，非獨立樣本的顯著性檢定。只有一個訓練 seed，且 validation 曾用於選模。cluster ID 不跨模型對應。
