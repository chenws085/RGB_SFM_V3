# Concept intervention visualization

概念概覽：concept_overview.png；逐影像對照：paired_effects.png；完整圖集：intervention_report.pdf。

正的 logit drop 表示目標分數下降，負值表示上升。Effect gap 為概念下降量減隨機下降量。黑點為影像，已在影像內平均 random repeats。

組合圖只在聯合概念存在、且 A/B/A+B 都有結果的相同影像上比較；joint_minus_sum 是描述性非加成量，不能直接視為因果交互作用證明。

影像框為 token 網格位置，不是完整感受野。此為小樣本功能展示，無信賴區間或显著性宣稱；隨機對照未匹配位置／前景。
